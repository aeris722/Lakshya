# 🎯 Lakshya

*A daily discipline system: complete tasks → earn XP → survive penalties → climb the weekly league → protect the streak.*

Built as a single-file web app. Works on any phone browser. All data stays on your device.

---

## ☀️ Weekday Routine — 12 Tasks · Max 710 XP

| Task | Time | XP |
|---|---|---|
| ⏰ Wake up | 6:20 AM | +50 |
| 💪 Workout | 10 min | +60 |
| 🧘 Meditate | 15 min | +70 |
| 📓 Journal | — | +50 |
| 💊 Medicine | — | +0 |
| 🌆 Wake up | 3:20 PM | +60 |
| 📚 Study session | 3:40–6:00 PM | rating ×1 · max 100 |
| 🛋️ Relax | — | +0 |
| 🌙 Study session | 6:30–9:30 PM | rating ×1 · max 100 |
| 🏠 Talk with parents | — | +0 |
| 🌌 Study session | 10 PM–12 AM | rating ×1.5 · max 150 |
| 🧾 Slip | end of day | +70 |

> **Study sessions:** tap → rate productivity 1–100 → earn `rating × multiplier`.
> Example: 80 on the night session = 80 × 1.5 = **+120 XP**.

## 🏆 Weekly League — resets every Monday

| League | Requirement |
|---|---|
| 🥉 Bronze | 3,899 XP · 70% of week |
| 🥈 Silver | 4,456 XP · 80% |
| 🥇 Gold | 5,013 XP · 90% |
| 💎 Diamond | 5,570 XP · 100% — a perfect week |

**Penalties** — applied only to finished days (today is never penalized mid-day):

- A day earning **under 70% of its own max** (< 497 weekday · < 707 weekend) → **−50**, replacing that day's points
- 🧾 **Slip unchecked** → another **−50**
- Both stack → a skipped day costs the week **−100**

---

## 🔥 Streak

Counts only **perfect days** — every task checked (12/12 weekday · 13/13 weekend).
Miss one thing → streak resets to 0. Zero-XP tasks (medicine, parents) count too.
The calendar colors each past day by how much of it you completed.
